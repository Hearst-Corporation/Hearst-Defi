🔴 Issues P0 — Bloquants
  • CRITIQUE SLUG MISMATCH — /vaults/yield-vault → 404 sur toutes les pages
    Tous les liens de navigation pointent vers /vaults/yield-vault mais aucun VaultDeployment n'a id=yield-vault. Le vault réel est id=hearst-yield-vault, ticker HYV-A. Cause : 404 sur toutes les pages avec lien vault, y compris prefetch du chrome applicatif. Fix : mettre à jour product-select-card.tsx et tous les liens nav.
  • CRITIQUE INVEST FLOW BLOQUÉ — /vaults/yield-vault/invest renvoie 404
    hearst-yield-vault a un contractAddress vide → isPlaceholderVault() retourne true → notFound(). L'intégralité du flow de souscription est inaccessible tant que contractAddress n'est pas renseigné en DB.
  • CRITIQUE AUTO-REDIRECT BUG — Pages produit redirigent en 1–3s sans action utilisateur
    Multiples pages authentifiées (/onboarding/identity, /profile, /legal/*, pages admin) redirigent spontanément vers d'autres routes en 1–3s. Cause racine non identifiée — probablement un composant client dans le layout partagé (chat rail, HeaderConnect, ou InvestorRailIntra) déclenchant router.push() en side-effect.
  • CRITIQUE WIZARD AUTOSAVE RSC LOOP — /admin/vaults/new bloque à l'étape 4
    Le server action saveWizardStep() déclenche un RSC refetch de la page force-dynamic qui réévalue showGate=true (draft existe, resumeAcknowledged=false) → réaffiche le ResumeDraftBanner à chaque autosave. Les étapes 5–7 sont inaccessibles. Fix : autosave ne doit pas déclencher de RSC refetch, ou URL doit porter resumeAcknowledged=true une fois le wizard démarré.
  • CRITIQUE LEGAL ROUTES INACCESSIBLES EN BROWSER — Override CSR sur /legal/*
    AppChrome (use client + next/dynamic) reroute les utilisateurs au moment de la réhydratation CSR, overridant l'exclusion de proxy.ts. Les pages /legal, /legal/disclaimer, /legal/terms, /legal/privacy sont SSR-correctes (HTTP 200) mais injoignables dans le browser en session authentifiée.
  • CRITIQUE /admin/governance/simulate-demo — Chunk compilé stale : toujours 404
    layout.tsx gate avec NODE_ENV === 'production' inliné à la compilation comme notFound() inconditionnel. Route permanentement 404 même en dev. Fix : supprimer .next et rebuilder, ou retirer la production gate.
  • CRITIQUE /api/admin/review-mode 403/429 STORM — Side-effects redirects admin
    L'endpoint /api/admin/review-mode est rate-limité (429) et forbidden (403) sur polling rapide. Le error handler côté client déclenche des navigations comme side-effect, causant des redirections imprévisibles sur toute la section admin.
  • CRITIQUE KYC ONBOARDING NON GARDÉ — Skip possible via "Continue to Wallet Binding"
    Sur /onboarding/identity, le lien "Continue to Wallet Binding" n'a aucun guard côté serveur ou client vérifiant la complétion du KYC. Un utilisateur peut bypasser entièrement la vérification d'identité et accéder à /onboarding/wallet.
  • CRITIQUE PLACEHOLDER SIGNERS EN PATH PRODUCTION — PLACEHOLDER_SIGNER_1/2
    PLACEHOLDER_SIGNER_1 et PLACEHOLDER_SIGNER_2 dans PROMOTE_DEFAULTS.signersWhitelist de actions.ts (/admin/projection) seront écrits dans les lignes VaultDeployment production via "Promote to Vault Draft". Doivent être remplacés avant tout usage.
  • CRITIQUE POST-LOGIN ?from= IGNORÉ — Redirect vers /admin/roadmap au lieu de la destination
    Après login, les utilisateurs sont envoyés sur /admin/roadmap au lieu de la route originellement demandée (ex: /vaults/yield-vault/invest). Le paramètre ?from= n'est pas honoré par la logique de redirect post-login.
  • CRITIQUE /api/auth/logout — 404 : endpoint manquant
    Aucun route handler n'existe à /api/auth/logout. Le SDK Privy tente d'appeler cet endpoint et échoue. La fonctionnalité de déconnexion est cassée pour tout code path utilisant cette route.
  • CRITIQUE MOCK DATA PROVENANCE='live' — Violation règle #2 CLAUDE.md
    MOCK_PORTFOLIO dans les pages debug positionne source='live' sur des données statiques entièrement mockées. Tout admin/QA lisant ces pages voit une fausse provenance Live. Violation directe de la règle non-négociable #2.
  • CRITIQUE DOUBLONS DISTRIBUTION DB — Deux lignes identiques /admin/distributions
    L'historique des distributions montre deux lignes identiques : hearst-yield-vault / 2026-05 / $800,000.00 / 0 recipients / May 29 2026. Probablement double-seedé. Impacte les calculs de distribution et l'historique investisseur.
