DETERMINISTIC INTENT ROUTER v2 Pre-LLM
src/lib/agentic/intent-router.ts · intent-router-rules.ts · intent-router-negation.ts

PRODUCT WORKSPACE INTENT CLASSIFIER Pre-LLM check
src/lib/llm/product-workspace-intent.ts · classifyProductWorkspaceIntent()
Pure regex classifier. Runs if the intent router did not already resolve to a hard fast-path. Distinguishes: product_creation (creation verb + product noun), product_framing, explicit_simulation, and mixed kinds. A bare creation verb ("create") without a product noun → none (not a product intent, falls to LLM). "Create projection" → none, not product creation.
Pure No I/O Prevents projection/product confusion
LLM CALL (when needed)
src/lib/llm/chat-agent.ts · runChatAgent() — OpenAI GPT-4.1 (ADR-011)
Called only when deterministic routing does not resolve the intent. System prompt is role-aware (LP vs admin). Admin mode can call bounded read tools (navigate, get specs, get vault data) and write tools (behind HITL confirmation token). LP mode has NO write tools. Output streamed to client.
GPT-4.1 LP: read-only tools Admin writes: HITL token required
OUTPUT GUARD Post-LLM
src/lib/llm/output-guard.ts · guardChatStream() · chatOutputViolation()
Wraps the token stream. Holds a 64-char look-back buffer. On each chunk checks: (1) containsForbiddenChat() — forbidden words (guarantee, promise, garanti, sans risque, etc.) with negation-aware matching. (2) hasSinglePointApy() — APY must be a range, never a single point. On violation: emits \x00ERROR: sentinel, aborts stream. The offending text is never delivered. Yield-keyword-aware: holds emission at last sentence boundary when a yield sentence is in progress.
Forbidden words APY range enforced Violating text never emitted
CLIENT — NAV / CANVAS / RESPONSE Final state
cockpit-shell client (chat renderer, canvas handler, nav signal consumer)
Client receives: streamed text response, OR nav command (→ page redirect), OR canvas signal (→ Product Workspace / Scenario Lab panel opens), OR error sentinel. No financial or custodial action is ever taken automatically.
