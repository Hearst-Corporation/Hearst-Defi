02

Architecture doctrine

cockpit-shell/

Global 3-column shell (RailLeft · CenterPanel · RailRight chat) + layout + the --ct-* token source. CockpitShell wraps every product surface; page shells mount inside CenterPanel.

src/components/catalyst/

Canonical UI components — Button, Badge, Table, Input, Card, BentoBadge, CockpitButton, EmptySurface, PageShell. All tokenized via --ct-*; focus rings de-blued to --ct-accent (#184).

src/components/ui/

Temporary legacy compatibility layer. 188 files still import it; 5 primitives already re-export Catalyst, 19 remain autonomous (migrating by lot). No new autonomous visual component should land here.

Render paths

Pages→ui/* wrapper (compat)→Catalyst→--ct-* tokens
Pages→Catalyst direct→--ct-* tokens
cockpit-shell→layout rails + tokens

Decision: nothing is deleted brutally; everything migrates progressively; ui/* becomes a façade; pages migrate by lot.
