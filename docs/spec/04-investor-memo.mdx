# Investor Memo

## Purpose

Generate an 8-page PDF in 1 click that the sales team hands to a LP committee.

## Structure (8 pages)

| Page | Question answered | Components |
|---|---|---|
| 1 | (cover) | Hearst logo + client logo, product name, date, "Confidential", RM contact |
| 2 | What is this? | Pitch paragraph (mining note, BTC accumulation, 24-month term) + 6 key metrics |
| 3 | Where does the return come from? | Mining causal diagram + 3-pocket breakdown (B1/B2/B3 · 40/27/33) + BTC-accumulation logic |
| 4 | What can go wrong? | 3 PTAI blocks (Bear, Mining Compression, Extreme Stress) |
| 5 | What does the note do if things go wrong? | Curtailment + vending curve + take-profit rules + last action |
| 6 | How are projections calculated? | Methodology v3.0, assumptions, confidence explained, data sources |
| 7 | What is verified? | Mini Proof Center — audit, attestations, on-chain links, methodology version, freshness |
| 8 | What is not guaranteed? + What decision is requested? | 5 risks + disclaimers + subscription terms + contact |

## Generation

- 1 master template, only variable fields: `client_name`, `client_logo`, `generated_at`
- `react-pdf` composable rendering
- Generation < 5s target
- Watermark "DRAFT" when MVP / seed data, removed in production
- Audit trail: every export stored in `report_exports` table with `methodology_version`

## Disclaimers (templated, never AI-generated)

- "Past performance does not guarantee future results."
- "Projections are conditional on stated assumptions. Returns are not guaranteed."
- "Return is accumulated in BTC over a 24-month term and delivered at maturity — there is no
  periodic cash distribution."
- "Subscription minimum $250k and 60-day soft lock-up are contractual / applicative, not
  enforced on-chain."
- Jurisdictional disclaimers (legal review S11–S12)

See `/docs/methodology/v3.0.md` for the full methodology block.
